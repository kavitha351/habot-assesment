# Habot Hiring Project

## Objective

Provision secure GCP infrastructure using Terraform, implement a fail-closed CI/CD pipeline, and demonstrate strict schema validation using Django REST Framework.

## Components

- Google Cloud Storage Bucket
- BigQuery Dataset
- IAM Least Privilege
- GitHub Actions Pipeline
- Django REST Serializer

## Security Features

- Uniform Bucket Level Access
- Public Access Prevention
- Least Privilege IAM
- Terraform Validation
- Secret Detection
- Fail Closed CI/CD

## Terraform Implementation

```
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
```
